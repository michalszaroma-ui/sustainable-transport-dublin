# Sustainable Transport in Dublin
 
H6WD Web Design and Development - CA2 Group Project
National College of Ireland, 2026
 
**Live site:** https://michalszaroma-ui.github.io/sustainable-transport-dublin/
 
## Topic
 
Sustainable Transport in Dublin, addressing UN Sustainable Development
Goals 11 (Sustainable Cities and Communities) and 13 (Climate Action).
The site covers cycling, the Luas tram network and Dublin Bus as
lower-carbon alternatives to private car journeys, and includes a CO2
commute calculator.

- `styles.css` - single shared stylesheet used by all six pages
- `calculator.js` - CO2 commute calculator (DOM, input validation)
- `images/` - WebP images optimised with Squoosh

HTML5, CSS3 and JavaScript. Written in Sublime Text and
